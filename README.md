# Computational Neuroscience | Machine Learning | Computer Vision

I am a scientist and machine learning practitioner working at the intersection of **neuroscience, AI/ML, computer vision, and quantitative data analysis**. My work focuses on developing computational approaches for extracting meaningful information from complex biological and behavioral datasets.

My projects include deep-learning-based behavioral tracking, electrophysiology and neural waveform analysis, reinforcement learning, scientific image analysis, and research database/tool development.

## Featured Projects

**Methods:** pose estimation · deep learning · video analysis · behavioral quantification

### 🧠 Neuropixels & Neural Data Analysis

### 🤖 Deep Reinforcement Learning

Implementation and evaluation of reinforcement-learning approaches using **PyTorch**, convolutional neural networks, and vision-based environments.

**Methods:** DQN · CNNs · reinforcement learning · model evaluation
